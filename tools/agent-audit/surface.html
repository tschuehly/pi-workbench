PI WORKBENCH · WORKING MODE

How Pi uses instructions

Working Mode changes guidance for the next prompt. It does not change permissions, remove project rules, or rewrite instructions already in the conversation.

THE WORKING CONTEXT

Pi builds context, then runs a model-and-tool loop

Before the model answers, Pi assembles the conversation with its base instructions, project rules, tool definitions, and an advertised skill catalog. Working Mode adds the selected Alignment and Checking guidance to those instructions for the next prompt. The axes are independent: changing one does not choose the other.

  1. ContextConversation, instructions, rules, tools, skill catalog
  2. ModelProduces text or requests a tool
  3. Tool resultPi runs the tool and adds its result to context
  4. Model or answerThe model uses results to continue or answer

CHECKING

The minimum evidence before completion

unset
Add no selected floor; explicit direction, project policy, and task consequences still apply.
light
Inspect or exercise the changed result directly.
tests
Run relevant automated tests and report the exact result.
adversarial
Produce deterministic evidence, then obtain a fresh independent challenge.

SKILL DISCOVERY

A catalog entry is not a loaded skill body

The advertised catalog gives the model a skill's name, description, and file location so it can discover relevant help. Checking changes which skills are advertised: tests adds tdd; adversarial also adds code-review and ponytail-review.

Skill text enters context when the agent reads the file or you explicitly invoke the skill. Hiding a catalog entry does not uninstall the skill, remove its command, erase instructions already loaded into the conversation, or override project rules.

ILLUSTRATION · NOT THE LIVE SELECTION

Plan + tests

The model is instructed to confirm the task's direction before implementation and to run relevant automated tests before claiming completion. The catalog advertises tdd for discovery, but discovery alone does not require test-first development.
