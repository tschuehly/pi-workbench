# Routing rationale and calibration

The authoritative current role-to-binding mapping lives in `routing-policy.json`. These bindings
graduated as a provisional Pi adapter from the skill-incubator policy; evaluate them from Workbench
run evidence rather than treating them as permanent model ownership. The router resolves one binding per invocation from Cognitive Role, author model family, and any
reviewer-family exclusions. The lead still sizes and assembles the checking panel; Alignment remains
a separate commitment boundary, not a mutation gate.

The Sol ladder carries routine through consequential GPT work. Higher Model Effort follows novelty and consequence rather than code volume; maximum effort remains exceptional because marginal quality can consume disproportionate quota.

Astra is an explicit attended Worker override, not a default binding. Use it for long-horizon coordination, difficult engineering or migration work, consequential computer/browser operation, and high-context escalation; keep routine implementation and mechanics on cheaper bindings until Workbench run evidence justifies promotion. Astra is in the same OpenAI family as Sol and supplies no independent review. See [`gpt-6-astra-strengths.md`](../../../docs/research/reports/gpt-6-astra-strengths.md).

Claude capacity is reserved for specialist value: Sonnet investigates, Fable judges or challenges OpenAI-authored work, Opus 5 synthesizes system models or reviews high-risk OpenAI-authored diffs, and Haiku handles mechanics. When the author uses Anthropic, the independent roles route to Sol instead. Cross-family selection follows the recorded author model's underlying family, including models hosted by GitHub Copilot. Family diversity supplies Independence, not correctness, and claims still require Primary Evidence.

Luna and Terra remain execution calibration candidates rather than normal fallbacks. The independent-role candidate lists include `github-copilot/grok-4.6` to make a distinct non-author-family panel selectable through exclusions. This is a routing capability, not a quality ranking. Compare judges using role, task shape, challenge lens, Model Effort, quota windows, outcome evidence, corrections, elapsed time, and any redo by another model. Other catalog families are recognized for author identity but gain no reviewer binding merely by being listed.
