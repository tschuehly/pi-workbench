# Evaluation ledger — 15 design reports and 39 tool notes

Selection favors **owner behavior/verdict → directly inspected implementation → design report →
scout note**, not adoption counts. This is evaluation for the specified four task sets, not a ranking
of whole products. Unique mechanisms are merged; the Kernel remains the communication layer.

Sources: [source register](SOURCES.md). `DR/` and `TL/` mean the two dated evidence directories under
`skill-incubator-private/atelier/docs/evidence/`. Each row names the supplied file and hashes its
inspected bytes; this remains reproducible even if an evidence file was not committed at repository HEAD.
Primary source revision/licence for every copied candidate idea is recorded in SOURCES and its README.
For scout-only rejections, the note is the evidence: we do not imply an independent source audit.
