# Offered content examples

Pick what answers the real task; these are evidence-backed options, not content rules or word budgets.
[Source IDs](SOURCES.md) name the retained evidence; the lesson is included here so it need not be fetched.

## Beside the judged item

- **Decision context + criteria-list:** Thomas wanted context inside each option and every alternative visible
  (VV lines 23, 34). Phase 0 failed on “a decision with no context” (PL §1, T5/R3). An example arrangement:
  evidence and sourced “Erfüllt / Offen” criteria immediately before the Kernel question, named as its `material`.
- **Evidence-disclosure:** the decisive result can stay visible, with reply → Calls → excerpt → raw behind
  native `<details>` (ME T6, RESULT-stack-final2). Label omitted log spans. Kernel jumps open details and
  badge closed ones with open items; a disclosure does not mean the human agrees (D113).
- **Inline-findings + revision-summary:** liked/disliked/fact/gap labels on the finding's own line were preferred
  (VV lines 15, 22). “What changed, from which version?” would have prevented rejecting fixes against an
  outdated render (VR T3, chat[142]); the Kernel separately marks earlier-version human feedback.
- **Manual-turn:** a copyable question followed by Expected bullets was requested “always” (ME O L2711,
  L2849). That shape transfers to verification instructions; a whole manual-run mode was not settled (ME §5 Q1).
- **Score-scale + action-dialog:** one 1–5 media score replaced a six-axis rubric; it is not approval (VR T5).
  Rare/risky actions in native `<dialog>` avoid permanent controls that “hide the bad things” (S2 L440).
  Start/stop handlers still need safe scope: an old stop recipe deleted chat history (ME T8, B §4).

## Navigation and evidence

- **Collapsible-outline + section-switcher + variant-picker:** a collapsing outline reserves no width;
  tabs can split unrelated work; one item at a time fits non-comparison tasks (VV lines 12–13, 21, 26).
  Native details are a safer starting point for Kernel jumps than hidden tabs. URL selection is an optional
  implementation, not an owner preference; scripts must restore it on `atelier:update` (Kernel contract).
- **Stage-nav + progress-groups:** “open questions per section” helped Thomas find where he was needed
  (PL T1, JV P4/1). Running / ready to judge / Decisions open can help re-entry (ME T3, WC T7).
  Counts need current data; Kernel closed-details badges already cover open items without a second counter.
- **Cost-ledger + run-now:** real-start elapsed, a currently checked PID, and one next action with its owner
  were requested (PL R1–R2, CB §3). Costs were report-only: absent is not zero, partial totals say partial,
  human wait stays separate from compute, and expense never stops the run automatically (PL R4, CB §5).
- **Source-reference + status-distribution:** pin evidence to the artifact's revision/hash; rebuilding at HEAD
  “would quietly change” comparison numbers (WC S L61). PASS / FAIL / ERROR / UNMEASURED / n.a. remain distinct:
  receipts were once green on the wrong master (PL T7, CB §4). The observation-stamp Component shows this boundary.
- **Frame-strip + safe-zone:** 278/318 media Comments were time-anchored (VR T2). An offered exhibit is frame
  at the cited second + seek link + version + full attributed quote (PL T4). Safe-zone geometry must come from
  the platform's calibrated constants, not illustrative guesses: it drove 13/28 early complaints (VR T1).
  `filter:none` on media alone cannot cancel a filtered ancestor; leave the entire media ancestry unfiltered.
- **Gate-detail + named-flow:** distinguish production's sequential fail-fast path from parallel diagnosis
  (PL T2: build.mjs:498 vs gate-matrix.mjs:43). Per check, the useful questions were: always does what, origin
  defect, effect on failure, proof limit, broken and clean expected/measured cases, runtime/source (PL T3, CB §10).
- **Copy:** natural German and “only what changes the decision” were owner preferences (VV lines 27–28),
  not permission to drop evidence. Prescriptive length guidance previously cut useful content by 44% (history report).

## Rejected or deliberately not extracted

- **P2 ledger as process explanation:** owner found the flow absent; flow/detail plus attempt history answered
  a different need than a ledger (VV; PL T2/T4).
- **Permanent Comment side panel, side chat, Comment tabs, gesture lanes or j/k paging:** width/scroll complaints
  ended in plain scroll after seven rewrites; Kernel already owns inline Comments and next-open navigation (VR T2; D124).
- **Quick tags and six-axis video rubric:** zero tag use; one score replaced the rubric (VR T2/T5). Separate
  correctness/completeness/taste still fits grading answers; it is not a universal media rubric (ME T4).
- **Visibility timers as agreement:** html-plan's 900 ms heuristic loses explicit intent; human action counts (D113).
- **Clipboard-first transport, detached pollers, custom stores or lifecycle engines:** use Kernel Delivery,
  Event Log and Updates; Copy is fallback (D109/121/125/128).
- **Mandatory STE, word budgets, one-exhibit rules or routing by named page type:** these erased useful content;
  layouts here are optional compositions (D117; history report).
- **Fake zoom, frozen ledgers, unlabeled green samples, live-from-in_progress, automatic cost stops:** recorded
  failures, not shortcuts to reliable status (PL §1/T2/T7/R4).
- **Selector hit as verification, exhaustive screenshot programs, Reset as a Verdict:** six claims were confirmed
  against a 404; actual scenarios matter, and Confirm/Redo was enough (LAU via WC T2/§3).
- **Default mobile/tunnels or multi-user auth:** Mac-local is the settled default (D132); a 390px embedded app
  tests that app, not mobile Atelier support. A standalone theme switch earned no remaining desktop need (VR T1).
- **Framework/CDN imports, graph DSL/Docker exporters, homemade layout/diff engines:** no owner-backed need in
  these candidates (landscape/design reports); project requirements can justify a library independently.
- **Diff-excerpt, sparkline, state-stepper:** mechanisms without an owner trial, not earned Components (judgement
  rows 8/32/34). Native `<pre>`, a table or an ordered list can answer a real task without a catalogue wrapper.
- **Edit-set, truth-change, run-request:** form editing/manual mode remained open; truth refresh was briefing-only;
  typed requests already belong to the Kernel (ME §5 Q1/Q3, B §2.5; judgement rows 9/26/37).
- **Word-overlap preference learning, fixed typed-page product policy, blind judging by default:** analyst/tool
  proposals, not owner decisions (AgentClick report; WC §5 Q3).
