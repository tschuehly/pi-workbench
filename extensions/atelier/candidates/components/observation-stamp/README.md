# observation-stamp

**Pick:** a status, result or comparison risks being mistaken for current truth.
**Lesson:** an observation needs time, exact input/build and source; history is not liveness. Missing,
failed, inapplicable and measured-zero are different. Keep partial cost totals and human wait explicit.

**Why:** Phase 0 used a frozen ledger's elapsed time, unrelated git changes and an “Unknown” wall;
ME ran a stale build unnoticed ([PL §1/R1–R4; ME T1](../../SOURCES.md)). Owner failures, not a visual preference.

**Use:** copy [example.html](example.html)'s section beside any claim. Replace synthetic observations
with measured values and immutable evidence links. `atl-ver` identifies the observation; it does not make
it fresh. No script, live timer or health probe is supplied. Folded in: run-now, source-reference,
status-distribution, cost-ledger; optional rollups are in TIPS.
**Skip:** an undated decorative status badge; if live supervision is needed, measure it in the project.
