# attempt-timeline

**Pick:** a final result hides the failed attempts, changed inputs or reasons behind it.
**Lesson:** every step within every attempt, including rejected ones; source identities, changes,
measured cost/time, and full attributed judgments rather than a success-only summary.

**Why:** Thomas made the timeline core although the agent ranked it last. He asked for every production
step, screenshots and judge comments ([PL T4, CB §8; VV line 37](../../SOURCES.md)).

**Use:** copy [example.html](example.html)'s ordered attempts; keep stable artifact/attempt/step Keys
and per-attempt versions. Pair with flow-map for process context, or video-stage for the current result.
A frame belongs at the cited second with source hash/seek link; missing frames stay missing. Historical
source ledgers must actually be maintained, not the frozen ledger that misled the original page.
**Skip:** pure commit chronology or a single untouched output. No timeline script or chart engine is needed.
