# One live run

Candidate Pattern · PL ME WC · Owner-spec. An offered arrangement, not a Registry admission or
content rule (107/117). Choose and change it for the task; no prescribed word count or page schema.

## When it helps
Follow one current run without mixing in unrelated git activity or old policy Decisions.

## Components and hierarchy
1. [run-now](../components/run-now/README.md) and [observation-stamp](../components/observation-stamp/README.md): current stage/attempt, next actor, real start and measured liveness.
2. [stage-nav](../components/stage-nav/README.md) locates the current path; [gate-detail](../components/gate-detail/README.md) explains the checks rather than referring to a separate old explainer.
3. [criteria-list](../components/criteria-list/README.md) precedes [decision-context](../components/decision-context/README.md) for accept / request changes / stop.
4. [cost-ledger](../components/cost-ledger/README.md) separates compute from human wait; another criteria-list holds pre-run corrections.
5. [attempt-timeline](../components/attempt-timeline/README.md) retains rejected as well as successful attempts; [revision-summary](../components/revision-summary/README.md) aids re-entry.

## Kernel / Keys
Run/stage/correction IDs, never p1–p7. Kernel Update preserves active input; live data refreshes on atelier:update. Delivery after 10 s is D129, not the old 30 s prototype behavior.

## Evidence for and against
[PL §2 / §2.1](../SOURCES.md#use-cases), CB and Opus 4751 domain Keys. Phase 0 failed despite HTTP 200: missing context, frozen timer, irrelevant files. [ME T3](../SOURCES.md#use-cases) adds overnight re-entry.

## Boundaries
Only a current project probe establishes a live PID. Costs are reported, not an automatic stop. G0–G6 do not replace Review Studio storyboard/cut/final approval gates. Data is read-only under D130.
