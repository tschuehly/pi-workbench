# Orient, then inspect evidence

Candidate Pattern · WC ME PL · Mechanism. An offered arrangement, not a Registry admission or
content rule (107/117). Choose and change it for the task; no prescribed word count or page schema.

## When it helps
Help a returning owner find the conclusion and inspect progressively deeper evidence without losing source identity.

## Components and hierarchy
1. [revision-summary](../components/revision-summary/README.md) or [inline-findings](../components/inline-findings/README.md) provides an offered conclusion-first entry.
2. [collapsible-outline](../components/collapsible-outline/README.md) locates topics; [flow-map](../components/flow-map/README.md) is optional when there is a real structure.
3. [evidence-disclosure](../components/evidence-disclosure/README.md) moves Summary → Explanation → Evidence → Raw; [source-reference](../components/source-reference/README.md) stays nearby.
4. [diff-excerpt](../components/diff-excerpt/README.md) or [state-stepper](../components/state-stepper/README.md) can be the exhibit when a changed line or transition explains the claim.

## Kernel / Keys
Claim/evidence Keys with source revisions. Expanded or clicked material can count as opened (113); scrolling alone cannot. Comment and Unanchored handling remain Kernel behavior.

## Evidence for and against
[ndrstnd](../SOURCES.md#ndrstnd) zoom ladder; [WC §2 T1/T3](../SOURCES.md#use-cases) owner asked chat for a conclusion already buried in IDX. [VV](../SOURCES.md#owner) dislikes excess text but imposes no word budget.

## Boundaries
A rational reconstruction is not a commit chronology. The ladder is optional; never collapse evidence the immediate Decision depends on. Diff raw links must point to real immutable artifacts.
