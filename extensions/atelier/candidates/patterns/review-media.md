# Review media items one by one

**Pick when:** the human watches/listens, points at a moment, and judges the current artifact.

**Hierarchy:** current version of one large item → time-local evidence and Comments → Decision on that item
→ optional simple score/rare actions → prior attempts. Ordinary scroll keeps longer threads reachable.
A frame exhibit carries the cited second, source version and full attributed judgment, not a random thumbnail.

**Compose:** [video-stage](../components/video-stage/README.md) for native playback and time anchoring;
[review-filter](../components/review-filter/README.md) for ready/unjudged items;
[attempt-timeline](../components/attempt-timeline/README.md) when explaining revisions matters.
The filter is optional for a single item; timeline history is not another simultaneous comparison player.

**Why:** 278/318 Comments had timestamps; decisions hidden in popups were missed and had to move onto their
videos. A six-axis rubric became one score; seven navigation rewrites ended in plain scroll. A newer render
was missed when judging a fix ([VR T2–T5; VV lines 25–26](../SOURCES.md)). Those are source-use observations.

**Does not fit:** side-by-side variant comparison or grading factual answers. Kernel media Comments record
time but provide neither captured frames nor seek-on-jump. Real media, captions and calibrated safe zones
remain project inputs. Score is not production approval; approval must bind to the actual master bytes.
