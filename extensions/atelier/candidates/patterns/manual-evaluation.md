# Manual console round

Candidate Pattern · ME · Owner-spec. An offered arrangement, not a Registry admission or
content rule (107/117). Choose and change it for the task; no prescribed word count or page schema.

## When it helps
Let the owner ask questions in the product console while the Page keeps expectations and results organized.

## Components and hierarchy
1. [observation-stamp](../components/observation-stamp/README.md) identifies the actual console build.
2. [manual-turn](../components/manual-turn/README.md) gives one copyable quote and expected bullets, with paste/export intake.
3. [evidence-disclosure](../components/evidence-disclosure/README.md) shows the resulting reply and tool calls; [grade-axes](../components/grade-axes/README.md) records the distinct judgments.
4. [item-pager](../components/item-pager/README.md) advances after a saved result, with [progress-groups](../components/progress-groups/README.md) tracking the set.

## Kernel / Keys
Test Keys and result Keys stay separate. Reply intake is a Request, human grading a Verdict, Taste a Comment. The agent acknowledges actual receipt through the Kernel.

## Evidence for and against
[ME §2 T2](../SOURCES.md#use-cases), owner O L2711/2849 and repeated watcher failures. WC verification card is the source arrangement; it is not evidence that a watcher exists.

## Boundaries
Manual mode is offered alongside automated eval, not a settled requirement for the first ME build. A watcher/export parser is project work; do not claim automatic receipt without it.
